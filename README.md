# Office-Downgrade-Script
This tool is aimed at IT professionals that want to upgrade/downgrade Microsoft Office on mass using a single Powershell script.

This tool downloads the Office Deployment Tool, and creates two configuration XML files - one two uninstall office, and the other to install office.

In its current state, it only downloads office build 16.0.20026.20140 64 bit and disables automatic updates, however this can easily be edited before running. Please check the official Microsoft documentation for this
